# Island Assault: Unity starter game

Island Assault is an island base-building and beach-assault strategy game in the style of Boom Beach. Everything is generated by code: the 3D models, the island, the animated ocean, the effects and the UI. You don't need to import any art. Open it in Unity, press Play, and it runs.

## Setup (about 10 minutes)

1. Install **Unity Hub**, then install **Unity 6 LTS** (6000.x). Unity 2022.3 LTS also works.
   During the install, tick **Android Build Support** (and **iOS Build Support** on a Mac) so you can export to a phone later.
2. In Unity Hub, click **New project**, choose the **Universal 3D** template (URP), give it a name and create it.
3. Unzip this package and copy the `Assets/IslandAssault` folder into your project's `Assets` folder.
   You can drag it into the Project window in Unity.
4. Wait for Unity to finish compiling. Check that the Console shows no red errors.
5. Open any scene (the template's `SampleScene` is fine) and press **Play**.

The game starts by itself. There's no need to add anything to the scene.

## How to play

**Home island**

- Drag to move the camera. Use the mouse wheel or pinch to zoom.
- **BUILD**: pick a building, drag it into place (or tap a spot) and press **PLACE**.
- Tap a building to open its panel, where you can **UPGRADE** or **MOVE** it.
- You have 2 builders, so only 2 constructions or upgrades can run at once.
- Gold Mines and Sawmills produce over time, even while the game is closed. Tap the bubble to collect.
- Upgrading the Headquarters raises your storage, unlocks more buildings (Sniper Tower at HQ 2, Mortar at HQ 3) and unlocks the Rocketeer.
- **ARMY**: choose which troop each Landing Craft carries. The options are Rifleman, Heavy and Rocketeer.

**Attack**

1. **ATTACK!** shows you an enemy island and the loot you could win. **FIND ANOTHER** costs 50 gold.
2. Press **ATTACK!** to pay for your troops, then tap a beach. Your boats land there.
3. Troops automatically go for the nearest building.
4. Use the gunboat abilities by picking one and tapping the island:
   - **Flare**: troops run to that spot.
   - **Barrage**: artillery strike on that spot.
   - **Medkit**: heals troops in that area.
5. Destroying buildings gives you more energy. Destroy the **Headquarters** to win.
6. Victories make the next enemies stronger.

Progress saves automatically to `Application.persistentDataPath`. To wipe your save, tap **New game** twice.

## Building for phone (Android)

1. Go to **File > Build Profiles** (or **Build Settings** in 2022), select **Android** and click **Switch Platform**.
2. In **Player Settings**, set the Company and Product name. The game already locks itself to landscape.
3. Run the menu item **Island Assault > Prepare for Build** once. It keeps the transparent water and glow effects in builds.
4. Connect your phone with USB debugging enabled and click **Build And Run**.

iOS works the same way, but you need a Mac with Xcode.

## Making it look even better (optional)

- In the URP template's **Global Volume**, add or adjust **Bloom**, **Tonemapping (ACES)**, **Color Adjustments** (saturation +10) and **Vignette**.
- On the URP asset, raise **Shadow Distance** to about 150 and set **Soft Shadows** to High.
- You can later replace the generated models with real 3D art. Free low-poly packs from the Unity Asset Store or Kenney.nl work well. Each building's look is defined in `BuildingModels.cs`.

## Code map

| File | What it does |
|---|---|
| `Core/GameManager.cs` | Auto-starts the game, switches between home and attack, handles the economy and saving |
| `Core/GameData.cs` | **All balance numbers** (costs, HP, damage, timers, unlocks) and the save format |
| `Core/GameInput.cs` | Mouse and touch input (works with both Unity input systems) |
| `Core/CameraController.cs` | Pan, zoom, pinch and screen shake |
| `World/Island.cs` | Procedural low-poly island, palms, rocks and the build grid |
| `World/WorldEnvironment.cs` | Sun, fog, animated ocean and clouds |
| `World/BuildingModels.cs` | 3D models for every building at every level |
| `World/Building.cs` | Building health, construction and destruction |
| `World/FX.cs` | Explosions, smoke, splashes and heals |
| `Base/BaseMode.cs` | Home island: building, upgrading, collecting and army setup |
| `Battle/AttackMode.cs` | Enemy generation, landing, gunboat abilities, win and lose |
| `Battle/Troop.cs`, `Defense.cs`, `Projectile.cs`, `Boat.cs` | Combat AI |
| `UI/*` | Screens built in code (no prefabs) |

To tweak the game, start with `GameData.cs`. Every number that matters is there.
